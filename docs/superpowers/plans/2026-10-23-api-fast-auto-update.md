# API Fast 自动适配

目标：从桌面切换器使用 API 登录时，商店更新后自动检查并重建 Fast 副本，无需每次手动运行修复。已有语义补丁 v2 继续负责界面与请求判断，不承诺任意未知结构都兼容。

1. 启动流程：显式开启自动适配并保存本机 Node/解析器路径；API 登录启动时先校验当前副本，仅在需要时重建。个人账户不触发自动构建。禁用操作同时关闭自动适配。
2. 安装事务：独占 update.lock，临时目录构建，签名/完整性/版本复核后发布；旧清单在失败时保持可恢复。保留失败文件，不覆盖未知目录。已有完整构建可恢复清单。
3. 重试：按官方包与补丁工具/依赖身份记录失败；同一失败不每次启动重复耗时构建。新包、新补丁或手动重新开启可重试；失败通过原有降级提示显示。
4. 分发与落地：更新打包文件清单、说明和聚合测试；同步实际桌面入口所用工具，启用本机配置，在当前新版本上实测自动重建与隔离启动。

验收：模拟未启用、个人账户、有效副本、官方更新、锁冲突、构建失败、缓存失败、新版本重试、依赖丢失与禁用。安装器测试覆盖失败保留旧清单和中断恢复。运行 Node 补丁回归、PowerShell 启动及构建测试。真实执行当前版本自动构建，验证官方源未变，隔离启动主进程及 app-server 正常。不会为此发送付费请求或关闭正在工作的客户端。
