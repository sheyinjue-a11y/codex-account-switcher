# macOS native switcher / v0.2.0 preview

## Scope and decisions

- Native SwiftUI macOS 13+ app, Chinese UI; Universal Apple Silicon/Intel binary. No terminal in daily use. Official Codex app required; use its bundled CLI or a user-selected official CLI for browser login.
- Keep one existing `~/.codex`. Never swap/copy/delete history, databases, projects, skills, plugins, MCP settings, memories, or workspaces. Change only `auth.json` and allowlisted root routing/auth-storage settings in `config.toml`. Shared non-routing text remains intact.
- ChatGPT accounts and Responses API profiles; import current file login, isolated browser login/cancellation, rename, edit inactive API, delete inactive profile, switch/open, interrupted-switch recovery.
- Encrypt vault and journal with AES-GCM; master key in macOS login Keychain (not iCloud). Active auth remains file-backed as required by Codex. No token command-line arguments or logs.
- Single-instance file lock, no symlink/hardlink state targets, private files, atomic replacement, save refreshed current credentials, refuse unknown identity drift, rollback on failure; interrupted recovery must not overwrite unexpected externally modified auth/config.
- Ask before normal desktop quit; never kill CLI/editor jobs. Refuse switch while Codex processes remain. No hot switching or simultaneous accounts.
- Reject custom CODEX_HOME, keyring-only import, custom provider/profile overrides and unsupported routing syntax rather than silently rewriting. UI explains file-login prerequisite. Windows remains unchanged.
- No signing identity supplied: ad-hoc signing only, no Apple notarization claim. Publish explicitly as preview; Gatekeeper approval belongs to the user. Do not disable security protections.

## Outcomes / order

1. `macos/Package.swift`, `Sources/SwitcherCore`, `Tests/SwitcherCoreTests`: state model, conservative config editor, encrypted storage, transactional engine. Prove fail-first for missing core behavior on GitHub macOS runner; then cover history invariance, refresh retention, drift, rollback/recovery, API validation, links, locking, and vault integrity.
2. `Sources/SwitcherApp`: native picker and dialogs, safe platform adapters, isolated cancellable login. Keep launch errors distinct from committed switch failures. Use native system fonts, navy/blue/teal palette, shared-workspace footer; focus on account selection.
3. `macos/scripts/build.sh`, `Info.plist`, macOS test/package workflow: build both architectures, `lipo`, ad-hoc sign, verify bundle, zip + SHA256. Render synthetic-data SwiftUI preview for review. CI tests must never access real accounts or paid APIs.
4. README, macOS guide, SECURITY, CONTRIBUTING, export allowlist: platform-specific downloads and honest limitations. Integrate only after tests/build pass; publish v0.2.0 preview with Mac app and unchanged Windows runtime.
