# v0.2.0 — macOS 原生桌面预览版

新增用于切换 **官方 Codex 桌面应用** 的 macOS 原生 SwiftUI 版本。不是 CLI 前端，日常使用不需要终端。

## 下载

- **Mac**：`Codex-Account-Switcher-macOS-universal.zip`。解压，将 `.app` 拖到「应用程序」，双击打开。
- **Windows**：`Codex-Account-Switcher-Windows.zip`。解压后运行 `Setup.cmd` / `Start.cmd`；Windows 运行逻辑保持不变。
- `SHA256SUMS.txt`：上述两个 ZIP 的 SHA-256 校验值。

Mac 工具支持 macOS 13+，包含 Apple Silicon / Intel 两种架构；官方 Codex 本身的系统/芯片支持以官方为准。

## Mac 版功能

- 中文原生窗口，导入当前文件登录、通过官方浏览器添加 ChatGPT 账号、保存 Responses API 地址/Key/模型。
- 账号重命名、非活动账号删除、非活动 API 编辑与 ChatGPT 重新登录。
- 用户确认后正常退出、切换并重新打开官方 Codex；不强制结束 CLI/编辑器任务。
- 继续共用 `~/.codex`，不分离或复制会话、数据库、项目、skills、插件、MCP、规则与记忆。只更新认证和必要路由配置。
- 钥匙串保管加密密钥，AES-256-GCM 保护账号副本与恢复记录；支持失败回滚、中断恢复、外部修改冲突保护。
- 首次从钥匙串/auto 登录切到文件登录前单独提示，并加密备份原文件/配置；不读取或改动官方钥匙串。

## 安装前请注意

- **没有 Apple Developer ID 签名或公证**，仅 ad-hoc 签名。macOS 可能阻止首次打开。核验来源/校验值后，由你本人决定是否在「隐私与安全性」允许；不要全局关闭 Gatekeeper 或绕过企业策略。
- 首次使用先退出 Codex 并备份 `~/.codex`；备份含敏感数据，请勿上传。
- 本地数据共享不代表云端数据跨账号互通；切换 API 后继续原会话可能把历史发送给新服务商。
- macOS 首版不迁移 Windows DPAPI 账号库，不支持自定义 `CODEX_HOME`、自定义 provider、配置 profile/强制登录覆盖；复杂根配置会保守拒绝修改。暂不提供付费连接测试按钮。
- 活动 `auth.json` 是官方客户端使用的文件凭据；加密的是工具保存的副本。不承诺抵御同用户恶意软件、磁盘故障或不配合的并发进程。
